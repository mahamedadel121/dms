## 10. Commands and conventions
- Root scripts (`package.json`): `pnpm db:up | db:down | db:status` (private Postgres cluster in `.pgdata` on :54329, idempotent), `pnpm db:migrate` (migrates `dms`, rebuilds `dms_template` + base seed), `pnpm db:seed` (base + demo), `pnpm db:generate` (fails with EPERM while any node process holds the Prisma engine DLL: stop api/worker/web before), `pnpm dev` (`scripts/dev.ts`), `pnpm demo [--rebuild] [--no-seed]` (`scripts/demo.ts`: generate, db:up, migrate, seed, build web if no `.next/BUILD_ID`, start api, worker, sim, web; logs in `.demo-logs/*.log`; Ctrl+C stops what it started, Postgres stays), `pnpm lint` (eslint flat), `pnpm typecheck` (`pnpm -r typecheck`), `pnpm test` (`pnpm -r test`), `pnpm ci` (powershell `scripts/ci.ps1`), `pnpm e2e`, `pnpm bot:sim`, `pnpm format`.

## 11. Known issues still open (`docs/PROGRESS.md`, `docs/CONTRACT_NOTES.md`)
- No UI to create/edit Request Types or create a new template (API partially exists; `POST /templates` missing).
- S/4HANA adapter: SOAP element names unverified, `findByReference` returns null (double-post risk on lost response with the real adapter); Cash Journal = interface only.
- Telegram bot never run with a real token (polling and webhook untested; simulator only). Email = stub. S3 storage = stub. Docker/Nginx/Caddy files never executed. Backups scripted but not executed.
- `/metrics` is a JSON stub and unauthenticated; no rate limiting on file URLs.
- No load test (50k requests); performance unmeasured.
- Queue shows a request twice when two parallel active steps are both yours.
- API returns some money totals without decimals (e.g. `"2090"`), line amounts as `"100.00"`; the web formats them.
- `pnpm demo` serves a production build; `next build` rewrites `apps/web/tsconfig.json` and `next-env.d.ts` (revert before commit). `pnpm db:generate` fails with EPERM while node processes are running (observed when starting `pnpm demo` while a stack was already up).
- Mock SAP ledger is per process (the seeded failure is a stored FAILED row; retry in `/sap`).
- Web lint config lacks `react-hooks` and `@next/next` plugins; no `eslint-disable` for those rules.
- `docs/CONTRACT_NOTES.md` open items: `@dms/db` seed imports shared by relative path; `@prisma/client` not an explicit dependency of `@dms/core`; `pageQuerySchema` duplicate-export notes were resolved by `platformPageQuerySchema` (check `tsc` on shared if contracts change); odd API contract: `GET /workflows` and `GET /templates` return arrays without `versions`; `POST .../preview` returns 200 raw body (not JSON), so the web uses raw `fetch`; web uses `GET /auth/me` to trigger a token refresh before the raw preview retry; `LOCKED` errors expose `error.details.userName`.
- Web UX issues (not bugs in PROGRESS) are catalogued in `docs/design/current/NOTES.md`.
